# Vehicle Rental System 🚗

A Java console application that demonstrates Object-Oriented Programming (OOP) core principles and clean architecture.

## 🌟 Key Features
- **OOP Core:** Built using Abstraction, Encapsulation, Inheritance, and Polymorphism.
- **Dynamic Pricing:**
    - `Car`: Standard daily rate calculation.
    - `Motorcycle`: 20% discount on total rental fee.
    - `Truck`: 50% surcharge rate.
- **Rental Management:** Real-time tracking of vehicle availability and rental operations using Java Collections (`ArrayList`).
- **Interactive CLI:** Menu-driven console interface for seamless user interaction.

- **Language:** Java
